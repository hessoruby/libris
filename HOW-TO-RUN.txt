Libris - Library Management System (Team AJP_11)

1. Install Java (JDK 17 or newer, free at https://adoptium.net).
   To check, open a terminal and type:  java -version

2. Windows:      open the folder javaproject\run and double-click run.bat
   Mac / Linux:  open a terminal in the javaproject folder and type:  bash run/run.sh

3. The browser opens http://localhost:8080 by itself.
   Log in with user name srm and password ap.

4. To stop the app, close the terminal window or press Ctrl+C.
   To get the sample data back: run reset.bat (Windows) or bash run/reset.sh (Mac / Linux), then start again.

"Port 8080 is busy" means the app is already running in another window.
